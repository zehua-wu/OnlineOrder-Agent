# Agent V2 入门解释

请从 [《从零理解 OnlineOrder Agent V2：从一句点单请求到真实购物车》](agent-v2-from-zero-zh.md) 开始。

它按八层展开：整体责任 → 模型与工具的实际数据交换 → Session与多轮 → 长短期记忆 → 加购确认与失败恢复 → 源码调用链 → 测试和评测 → 带预期结果的实操。

这份教程不要求你先懂Agent框架；每个环节解释它解决的问题、数据怎么流动、代码怎么执行、为什么这样分层，以及当前实现的限制。

已有的接口核查、设计摘要、完整Session样例、评测和面试材料仍在 [docs/](../docs/README.md)，适合理解教程后查阅。
